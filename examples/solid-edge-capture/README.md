# Solid Edge: capture required, provider preserved

[capture-required.json](capture-required.json) retains the actual intended
`burhop/SolidEdgeMCP` implementation and **`solid_edge`** application provider,
with precisely labelled historical evidence. It is a non-executable integration
template, not a valid runnable core package. Current binary identity, tool
snapshots and authorized model/source artifacts remain missing. A historical
local server UUID or commit does not supply those facts.

No mock is called Solid Edge, no fabricated version fills a required pin and no
neutral STEP file silently replaces the native sheet-metal model. The template
identifies which original Wright source must be supplied and preserved; the
source bytes are **not included**, and the template does not claim otherwise.

When an installation lacks a compatible local or remote Solid Edge provider,
opening and retaining this material must preserve all named identities, task
intent and supplied source bytes. Explain the missing capture/provider without
engineering calls. A complete valid process captured later may still remain
unavailable there; that availability condition does not invalidate its meaning.

The opt-in [capture and integration recipe](../../docs/wright-compatibility.md#real-solid-edge-capture-gate)
requires an authorized native model, frozen provider build and actual schemas.
Run only against isolated working copies after those facts are supplied. It
describes explicit provider selection, thickness readback, same-document handoff,
STEP export, partial failure and the lost-mutation-response case. No actual CAD
run is claimed by these examples or the mock conformance suite.

The observed Wright task uses AI-directed CAD work. Writing a deterministic
fixed-call sequence creates a newly authored variant unless equivalence is
established. Preserve the original, disclose missing facts and losses, and
identify one new authoritative graph; do not silently label `.wflow` as already
conforming. Replacing Solid Edge with another CAD application also requires an
explicit new revision, schema/argument/connection checks and renewed acceptance.
